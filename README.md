# Ingenio del Bosque

Juego de automatización y supervivencia ambientado en un bosque de piezas encajables. Diseñado en español para niños curiosos a partir de seis años.

## Jugar

El juego funciona directamente en el navegador y no necesita instalación. La partida se guarda automáticamente en el dispositivo.

## Publicación

Cada cambio enviado a la rama `main` se publica automáticamente en GitHub Pages mediante GitHub Actions.
